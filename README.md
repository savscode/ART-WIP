# ART – work in progress

Webbverktyget ART (Arkitektur, Resurser, Tid) – uppdaterad version för granskning.

## Så här öppnar du sidan

**Enklast – i webbläsaren:** https://savscode.github.io/ART-WIP/
(kräver att GitHub Pages är påslaget för repot)

**Lokalt på din dator:**
1. Klicka på den gröna knappen **Code** > **Download ZIP** här ovanför.
2. Packa upp zip-filen (högerklicka > "Extrahera alla").
3. Dubbelklicka på `Starta ART.bat` i den uppackade mappen. Ett svart fönster öppnas och sajten startar i webbläsaren.
4. Stäng det svarta fönstret när du är klar.

Dubbelklicka inte på `index.html` – sidorna laddas dynamiskt och behöver köras via en webbserver.
Om Windows visar "Windows skyddade datorn": klicka på "Mer information" och sedan "Kör ändå".

## Vad som har ändrats

- Projektexempelbilderna är komprimerade (från ca 340 MB till ca 25 MB, max 2000 px). Kolla gärna att kvaliteten håller på en stor skärm.
- Svaren ligger nu kvar om man laddar om sidan (F5). De töms när man stänger fliken eller går tillbaka till startsidan. Tidigare försvann allt vid omladdning.
- Startsidan har fått texten "Klicka för att börja" och kan även startas med Enter/mellanslag.
- Siffrorna 1–5, "läs mer"-pilen och "Se projektexempel" går att använda med tangentbordet (Tab + Enter).
- Felmeddelanden och varningar är översatta till svenska.
- Diagrambiblioteket (ECharts) är låst till en fast version.
